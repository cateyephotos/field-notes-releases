# Field Notes for Windows — releases

This repository holds the installers for Field Notes and the update feed the app reads. It contains no source code.

- **Install:** download `Field Notes Setup.exe` from the latest release.
- **Updates:** installed copies check this repository's latest release (about every 4 hours) and update themselves on restart. Each check shows GitHub your IP address; nothing else about you or your notes is sent.
- **Builds are not code-signed yet,** so Windows SmartScreen may warn when you run the installer.

Questions or problems: contact the Field Notes team through the beta list.
